LVM — Laboratório Virtual de Matemática (IFB)

Problema
Um TCC no IFB precisava trocar um mural de links estático por algo em que o aluno manipulasse a geometria, em vez de só ler sobre ela.
Solução
Laboratório em Next.js: o aluno arrasta o triângulo e vê as relações métricas valerem em qualquer posição. Os exercícios são gerados por semente, então os números mudam a cada tentativa. O Fermat, um assistente de IA, tira dúvidas no contexto da atividade sem entregar a resposta.
Decisões técnicas
Domínio matemático puro, isolado da UI. Geradores determinísticos cobertos por testes de propriedade (fast-check). O assistente roda no servidor, então a chave da API nunca chega ao navegador.
Next.js 16 React 19 TypeScript Vitest fast-check LLM

Organizador de Contas

Problema
O controle financeiro da família ficava em planilha, sem separação entre os dados de cada pessoa.
Solução
App em Next.js instalável como PWA: gastos e receitas, contas a pagar com vencimento, compras parceladas e resumo do mês.
Decisões técnicas
Cada usuário só enxerga os próprios dados, garantido no banco por Row Level Security (Supabase). Validação com Zod, migrations SQL versionadas e UI com shadcn/ui.
Next.js 16 React 19 TypeScript Supabase Zod PWA

App dos Catequistas — Paróquia São José

Problema
Cerca de 70 catequistas dependiam de grupos de WhatsApp e pastas soltas para achar materiais e avisos.
Solução
SPA em React com biblioteca de materiais, mural de avisos, calendário de encontros e painel para a coordenação publicar conteúdo. Está em uso pela equipe.
Decisões técnicas
Modelagem no PostgreSQL com permissões por Row Level Security: quem é coordenador publica, quem é catequista lê. Deploy na Vercel.
React Vite React Router Supabase PostgreSQL Tailwind
