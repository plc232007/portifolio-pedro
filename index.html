LVM — Laboratório Virtual de Matemática (IFB)

Laboratório de matemática desenvolvido para o TCC de um cliente do IFB. O aluno arrasta o triângulo e vê as relações métricas continuarem valendo em qualquer posição, com exercícios gerados por semente — os números mudam a cada tentativa, então não há gabarito para decorar. Inclui o Fermat, assistente de IA que tira dúvidas no contexto da atividade sem entregar a resposta. 

/* relações métricas — valem em qualquer posição */
a·h = b·c      b² = a·n
c² = a·m      h² = m·n

// exercício por semente → números novos a cada tentativa
Objetivo Substituir um mural de links estático por um laboratório interativo, em que a geometria é manipulada em vez de apenas lida
Meu papel Desenvolvimento completo — arquitetura com domínio puro isolado da UI, geradores determinísticos, testes de propriedade, assistente de IA server-side e deploy
Next.js 16 React 19 TypeScript Tailwind shadcn/ui Mafs KaTeX MDX Vitest fast-check LLM Vercel
